========================= inline css ========================= 

When you write inline CSS, you write standard CSS property/value pairs directly inside quotation marks:

HTML
<element style="property: value; property: value;">
Here is a practical example:

HTML
<p style="color: blue; font-size: 18px; font-weight: bold;">
    This text is blue, larger, and bold.
</p>
